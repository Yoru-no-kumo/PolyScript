# PolyScript AI — 의사결정 기록 (ADR)

버전 0.3 · 한국어 · 검토본 · 2026-10-19 (Asia/Tokyo)

## 1. 기록 기준

ADR 번호는 이번 세트에서 새로 부여했다. 과거 ADR을 복원한 번호가 아니다. 상태는 [Foundation](../foundation/project_foundation.v0.3.ko.md)의 정의를 따른다. 당시의 대안 비교나 결정 이유가 확인되지 않으면 추정하지 않는다.

근거 B1은 [승인 Foundation v0.2](../old/foundation/project_foundation.v0.2.ko.md), B2는 [기존 검토서](../old/reviews/foundation_review_notes.v0.2.ko.md)다. U1은 현재 Windows 개인용 전환·5개 문서 요청, U2는 한국어 작성·old 보관·세부 미결 유지 지시다. B2는 검토 자료이며 B1보다 우선하지 않는다.

## ADR-001 — Windows 개인용 데스크톱 전환

**배경:** B1은 다중 사용자와 공동 작업을 전제로 서비스·분산 실행 가능성을 포함했다. 현재 지시는 Windows 개인용 데스크톱으로 방향을 변경했다.

**결정 — 확정:** 개인의 Windows 앱 사용을 현재 제품 경계로 삼는다. 계정 서비스·역할 기반 공동 작업·SaaS 운영을 현재 필수 범위에서 제외한다. 2026-10-19에 지시를 확인했으며 과거 대화의 실제 전환 결정일은 확인하지 못했다.

**대안 관계:** 기존 다중 사용자 전제의 유지는 현재 지시와 충돌한다. 크로스플랫폼·완전 오프라인·원격 서비스 병행은 이번에 확정되지 않았다. 이 대안들을 과거에 실제 비교했다는 기록은 없다.

**영향:** 미디어 입력·작업 수명주기·저장·복구·배포를 데스크톱 기준으로 다시 설계한다. 기존 로그인·브라우저 흐름과 전역 역할을 자동 계승하지 않는다.

## ADR-002 — 제품 목적과 핵심 도메인

**배경·근거:** B1 §1·7·9·22의 목적은 현재 방향과 충돌하지 않는다.

**결정 — 유지:** Listening/Repeat/Shadowing과 독립 Script/Subtitle 출력, 다국어 설계, 기본 화자 재사용을 유지한다. Project Speaker·Persistent Speaker·Character를 구분한다.

**영향:** 개인용 전환으로 검수와 화자 근거를 제거하지 않는다. 상세 지원 범위·품질 수치는 미결이다. 당시 대안 비교의 전체 원문은 확보하지 못했다.

## ADR-003 — AI 후보·사용자 수정·의존성

**결정 — 유지:** AI 출력과 공식 채택 데이터를 분리하고 사용자 수정의 무조건 덮어쓰기를 금지한다. 입력·엔진·모델·설정·버전과 의존관계를 추적하며 가능한 완료 결과를 재사용한다.

**이유·근거:** B1 §11~13·18의 검수·추적·복구 요구를 계승한다.

**영향:** 원문 수정 후 기존 번역·자막을 최신으로 잘못 표시하지 않아야 한다. 차이 비교·충돌 해결 UI·트랜잭션·재실행 단위는 미결이다.

## ADR-004 — 목적·신뢰·수명주기 분리

**결정 — 유지:** 처리·저장·품질 개선·프로젝트 범위를 넘는 지식 활용·모델 학습·배포 목적을 구분한다. 보존은 시간·가치·허용 목적·의존관계를 함께 판단한다.

**이유·근거:** B1 §12·16·17. 신뢰와 개인 보유만으로 모든 사용 목적을 허용할 수 없다는 기존 원칙이다.

**영향:** Global Knowledge의 외부 공유 체계는 현재 필수 범위에서 제외하고 개인 라이브러리 범위 매핑은 미결로 둔다. [데이터 정책](../data/data_policy.v0.3.ko.md)의 상세 운용도 미결이다.

## ADR-005 — Learning과 모델 적용

**결정 — 원칙 유지:** 지식·통계·엔진 최적화와 조건부 학습을 분석 품질 개선에 활용한다. 사용자 수정의 자동 학습 데이터화와 평가·승인 없는 자동 모델 적용을 허용하지 않는다. 고급 학습은 v1 필수가 아니다.

**재검토 — 미결:** B1 §14의 Core/Learning 서버 물리 분리는 과거 확정이다. 새 제품의 실행 장비·격리·배치는 정하지 않았다. 조용히 삭제하거나 같은 장비·프로세스 실행을 승인한 것으로 취급하지 않는다. 실제 모델 학습 구현 전 별도 ADR로 대체·구체화해야 한다.

**영향:** 기본 화자 재사용을 위해 학습 서버 구축을 강제하지 않는다. ADMIN의 과거 승인 역할을 개인용에 그대로 적용하지 않으며 승인 UX는 미결이다.

## ADR-006 — 한국어 문서와 이전 자료 보관 (배치 방식은 ADR-008로 대체)

**당시 결정 — 배치는 ADR-008로 대체:** docs 바로 아래에 5개 Markdown 문서를 한국어로 작성하고 docs/00_foundation을 docs/old/00_foundation으로 이동하도록 했다. 기존 내용은 보존하며 sources는 수정하지 않는다.

**이유·근거:** U1·U2의 명시적 구성·언어·보관 지시다.

**영향:** 과거 ACCEPTED 상태는 당시 승인 이력이다. 새 문서는 자동 ACCEPTED가 아니며 장기 다국어 정책의 폐기를 의미하지 않는다.

## ADR-007 — 구현 기술과 실행 배치

**상태 — 미결:** U2는 아래 세부 결정을 미결로 유지하도록 했다.

| 선택 | 현재 상태 |
| --- | --- |
| UI·언어 | 프레임워크·구현 언어 미선정 |
| 저장 엔진 | 기존 PostgreSQL을 필수로 계승하거나 SQLite로 변경하지 않음 |
| 실행 구조 | 앱 내부 작업·별도 프로세스·서비스·큐 선택 미결 |
| 작업 수명주기 | 앱 종료·절전·재부팅 시 지속·중단·복원 범위 미결 |
| AI 실행 | 로컬·외부 API·원격 실행 허용 범위 미결 |
| 엔진·GPU | 대상 미디어와 장비 검증 후 선정 |
| 미디어 관리 | 복사·경로 참조·이동 복구 미결 |
| 배포 | 설치형·포터블·업데이트·모델 다운로드 방식 미결 |
| 보안·백업 | 자격증명·암호화·백업 위치·주기·복구 목표 미결 |

**제안:** 요구 경험과 장비 조건을 먼저 정하고 후보의 품질·속도·용량·운영 부담을 비교해 별도 ADR로 확정한다. 현재 특정 제품을 권고·선정한 기록은 아니다.

## ADR-008 — 목적별 폴더와 버전별 대표본

**상태 — 확정:** 2026-10-19 사용자 추가 지시. 문서 세트는 한국어 v0.3 검토본으로 유지하고 파일명에 v0.3을 명시한다.

**결정:** 현재 문서는 foundation·decisions·architecture·data·history로 구분한다. 이전 버전과 과거 참고 자료는 old 아래 목적별로 둔다. 같은 목적·버전·언어의 본문은 하나만 유지한다. AGENTS.md는 docs 전체에 적용하고 README를 진입점으로 사용한다.

**대체 관계:** ADR-006의 docs 루트 직접 배치를 대체한다. 한국어 작성·이전 버전 보관·확정과 미결의 분리는 유지한다. 파일명 정리 승인을 기존 파일명 보존 원칙의 예외로 적용하며, 결정 상태 자체는 승격하지 않는다.

**영향:** Foundation v0.2의 승인본 사본과 검토본을 대표 승인본 하나로 정리한다. Inventory와 변경 검토서는 목적이 다르므로 독립 보관한다. 상세 대응표는 [전환 기록](../history/migration_changelog.v0.3.ko.md)에 남긴다.
