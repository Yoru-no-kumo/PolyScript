## 1. 문서의 기준과 상태

이 문서는 기존 Foundation v0.2를 현재 제품 방향에 맞게 재구성한다. 이번 사용자 지시를 우선하고, 기존 승인 문서의 내용은 충돌 여부를 확인하여 계승한다. 서버·다중 사용자 전제를 현재 요구사항으로 자동 적용하지 않는다.

| 표시 | 의미 |
| --- | --- |
| 확정 | 이번 사용자 지시에서 직접 확인한 결정 |
| 유지 | 기존 승인 문서의 합의 중 현재 방향과 충돌하지 않는 내용 |
| 제안 | 검토를 위해 정리한 방향이며 승인된 구현 계약이 아님 |
| 미결 | 구체 선택이나 합의가 아직 없음 |
| 과거 기준 | 변경 전 설계의 기록이며 현재 의무로 자동 계승하지 않음 |

문서 작성 승인은 개별 설계의 승인과 구분한다. 새 문서 세트는 검토본이며 구현 완료 또는 정식 기준선 승격을 의미하지 않는다.

근거는 현재 사용자 지시와 [기존 승인 Foundation](../old/foundation/project_foundation.v0.2.ko.md)이다. 참조 대화 「PolyScript 설계 요약」 조회에서는 최근 assistant 답변의 본문 대신 참조 표시가 반환되었다. 따라서 확인되지 않은 데스크톱 세부 합의를 복원하지 않는다.

## 2. 제품의 목적 — 유지

PolyScript AI는 실제 영상·음성을 분석하고 사용자가 검수·수정한 결과를 Listening, 반복 청취, Shadowing에 활용하는 언어학습 제품이다. 원문·번역·화자·시간축을 연결하고, Script와 Subtitle을 독립적으로 내보낼 수 있게 한다.

특정 AI 모델 보유가 목적은 아니다. 실제 미디어를 분석하고 수정 가능한 학습 자료로 만드는 일관된 경험이 목적이다. 언어에 종속되지 않는 설계를 유지하며 KO/JA/ZH/EN은 초기 우선 언어이지 고정된 지원 한계가 아니다.

## 3. 현재 제품 경계 — 확정

현재 제품은 Windows 전용 개인용 데스크톱 애플리케이션이다. 개인의 프로젝트 생성·분석·검수·학습·출력을 중심으로 설계한다. 서비스 로그인, 전역 역할, 프로젝트 멤버십과 공동 편집은 현재 필수 흐름에서 제외한다.

SaaS·멀티테넌트 운영과 타 운영체제 지원은 현재 범위에 포함하지 않는다. 데스크톱 전환만으로 완전 오프라인, 모든 모델의 로컬 실행, 외부 API 금지, 특정 DB, 단일 프로세스 또는 설치 방식을 확정하지 않는다. 여러 Windows 계정의 사용과 앱 데이터 접근 방식도 미결이다.

## 4. 핵심 사용자 흐름

`프로젝트 생성 → 미디어 입력 → 처리 실행 → 상태·실패 확인 → 원문·화자·시간축 검수 → 번역·자막 검수 → 반복 청취·Shadowing / 내보내기`

기존 제품 흐름을 데스크톱 경계에 맞게 표현했다. 이는 고정된 엔진 실행 순서가 아니다. 학습 완료를 Script/Subtitle 내보내기의 전제조건으로 만들지 않는다. 미디어의 복사·경로 참조·이동 시 복구 방식은 미결이다.

## 5. 핵심 개념 — 유지

| 개념 | 의미 |
| --- | --- |
| Project | 미디어·설정·처리 결과·검수·출력을 묶는 단위 |
| Project Speaker | 프로젝트 안에서 구분된 화자. 실제 인물의 확정 신원을 뜻하지 않음 |
| Persistent Speaker | 프로젝트 간 재사용하는 장기 화자 프로필 |
| Character | 작품·프로젝트 안의 캐릭터. 화자와 독립된 개념 |
| Speaker Sample / Evidence | 화자 연결이나 판단을 뒷받침하는 자료와 출처 |
| Artifact | 입력·엔진·설정·의존관계를 추적하는 파생 산출물 |
| Canonical Data | 앱이 현재 공식 상태로 채택한 데이터 |
| Trusted Data | 별도의 신뢰 조건을 통과한 데이터 |
| Knowledge | 근거를 바탕으로 재사용하는 지식 |

화자와 캐릭터의 관계는 별도로 관리한다. 개인용이라는 이유로 화자 샘플의 출처나 프로젝트 간 재사용을 제거하지 않는다.

## 6. 설계 원칙 — 유지

- AI 결과는 후보이며 공식 채택·신뢰·학습 적격성과 구분한다.
- 재처리는 사용자 수정을 무조건 덮어쓰지 않는다. 충돌 처리 방법은 미결이다.
- 원문·화자·시간축 변경은 관련 번역·자막 등 후속 결과의 오래된 상태로 연결한다.
- 실패 원인을 확인하고 가능한 결과를 재사용해 필요한 범위를 다시 실행한다.
- ASR·화자 분리·정렬·번역은 교체 가능한 엔진으로 다룬다.
- 정보 손실의 비용과 추가 계산의 효과·시간·자원 비용을 함께 평가한다.
- 신뢰, 허용 목적, 현재 활용성과 장기 보존 가치를 구분한다.

Local-first와 Cost-first는 기존 우선순위로 유지한다. 외부 연결이나 실행 배치는 별도 결정이다. 배포에 독립적인 도메인이라는 기존 취지를 분산 인프라 구축 의무로 해석하지 않는다.

## 7. v1 범위 — 기존 목표 유지

실제 수십 분~약 1시간급 미디어의 입력부터 검수·학습·출력까지 연결된 제품 흐름을 목표로 한다. 원문·번역·화자·시간축 수정, 작업 상태·재시도, 기본 Persistent Speaker 연결과 재사용, Script 및 SRT/VTT/ASS 출력 목표, 재현 가능한 Benchmark와 개인 사용 검증을 유지한다.

형식별 구현 순서, 엔진 조합, 지원 파일 상한, 장비별 품질·속도·메모리 기준과 사용 검증 기간은 미결이다. 기존의 1시간 초과 지원 방향을 폐기하지 않지만 구체 성능을 보장하지 않는다.

고급 모델 학습, 완전 자동 인물 식별, AI 발음 채점과 대규모 운영은 v1 필수 완료조건에 넣지 않는다. 실시간 스트리밍의 채택 여부는 미결이다.

## 8. Learning의 위치

사용자의 언어학습 경험과 시스템의 분석 품질 개선을 구분한다. 품질 개선에는 지식 축적, 통계, 엔진 최적화와 조건부 모델 학습이 포함된다. 사용자 수정은 자동 학습 데이터가 되지 않고 새 모델은 평가·승인 없이 자동 적용하지 않는다.

기존 Core/Learning 서버의 물리적 분리를 Windows 개인용 환경에서 어떻게 재설계할지는 미결이다. 두 서버를 필수 설치하도록 계승하거나 동일 프로세스의 학습 실행을 승인하지 않는다.
